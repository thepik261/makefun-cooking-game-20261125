Warung Rush — run an Indonesian street-food stall: orders pile up on the board with countdown timers, you chop and cook ingredients, plate Nasi Goreng, Mie Goreng and Soto Ayam, and serve them before the customers walk out. A complete, original 2D canvas cooking game that plays offline in a desktop browser from its own files; an AI judge compares the games two at a time, places go by win rate, and the 10 best share $250.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play with WASD / arrow keys or the mouse, E or click to use a station.
